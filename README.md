# Tap-to-Shop Mobile App

A Flutter mobile application that allows users to snap or import a frame of what they're watching, identify on-screen apparel via Google Cloud Vision Product Search, and surface affiliate purchase links.

## Overview & Objectives

- **Goal**: Let users snap or import a frame of what they're watching, identify on‑screen apparel via Google Cloud Vision Product Search, and surface affiliate purchase links.
- **Core Value**: Eliminate the need for a bespoke vision dataset and custom model maintenance by offloading image processing to Google Cloud Vision.
